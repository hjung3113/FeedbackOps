# Code Index

This map is derived from the current source tree and
`docs/implementation/02-domain-module-boundaries.md`. The backend composes
module routes and services in `apps/backend/src/server.ts`; each module keeps
its owned writes and exposes explicit cross-module seams. Entity Links owns
canonical cross-system links, Core provides shared audit and idempotency
services, and modules register their own jobs. Frontend routes compose feature
components and typed API hooks; backend authorization remains authoritative.
Entry points in the tables below are repository-root-relative paths.
