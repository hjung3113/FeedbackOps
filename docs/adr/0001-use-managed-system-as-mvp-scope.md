# Use Managed System as the MVP scope

FeedbackOps is an internal tool for VOC and improvement work across independent analytics programs such as Tableau, Power BI, and Looker. We use **Managed System** rather than **Project** as the MVP scope because users need to file, triage, assign, filter, and report VOC against the actual analytics program the feedback concerns; **Project** is reserved for future execution grouping only if that distinction becomes necessary.
